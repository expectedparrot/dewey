# Version assessment

This is the 2026 *Survey Research Methods* publication of the same study represented by `src_2a843bf69441` as the 2025 arXiv preprint. It is retained as an archival published version and linked with `version_of`, but excluded as a separate analytic source to avoid double-counting the same four randomized experiments.

Local `paper2md` conversion failed because its fallback expected a missing intermediate image. PyMuPDF extraction confirmed the title, bibliographic metadata, abstract, conclusions, and references. The existing preprint record has a complete rendered Markdown representation and substantially the same bibliography, which had already been traversed with provenance.

The published version reports roughly 1,800 U.S. web-panel participants. LLM-driven confirmation and elaboration/relevance probes improved the detail and informativeness of open-ended responses; live coding was moderately accurate but susceptible to false positives associated with acquiescence; respondent experience declined slightly. Important limitations include a nonprobability sample, a single platform/model configuration, combined elaboration and relevance probing, and possible treatment-dependent attrition.
